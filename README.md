# nathantrost.com scripts

JavaScript for nathantrost.com, loaded from Webflow through jsDelivr at a pinned version:

    https://cdn.jsdelivr.net/gh/natrost/nathantrost-site@1.0.0/js/image-effects.js

A change reaches the site only when a new version is tagged here, the version in the Webflow link is updated, and Webflow is published.

CSS and the small scripts that must run before first paint, including the text reveal, stay in Webflow custom code.
